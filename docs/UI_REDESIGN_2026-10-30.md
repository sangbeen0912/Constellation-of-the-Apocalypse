# UI 개편 — 2026-10-30 / v5.4

## 후속 v5.4 — 하단 뒤로 가기/최적화

상단 복귀에 손이 잘 가지 않는다는 지시에 따라 뒤로 버튼을 하단 본문 왼쪽으로 이동했다. 시간·알림은 화면 좌하단, 속도 조작은 우하단이다. 세 구역을 겹치지 않도록 나눴다. 청색 바탕/흰 글자·화살표/큰 영역과 Escape를 유지한다.

성능 변경:

- 로그 한 줄을 공개할 때 Canvas 전체를 파괴·재생성하던 경로를 최대60개 Text 재사용으로 교체했다. 장면이나 실제 게임 행동 변경은 기존 Render를 사용하므로 모든 UI 갱신이 재사용된다고 주장하지 않는다.
- PixelPlate.Cut의 매회8꼭짓점 임시 배열3개를 제거하고 같은 꼭짓점을 직접 넣는다. 성유물ID8개도 호출마다 배열을 만들지 않고 한 번 만든다.
- UIOptimizationBenchmark와 tools/benchmark-ui.ps1은 Editor에서만 동일한 버튼 메시10,000회를 측정한다. 결과는 TestResults/ui-mesh-before.json 및 ui-mesh-after.json. 이 환경의 GC.GetAllocatedBytesForCurrentThread는 대조가 부적절해 결과에서 제외하고 실제1MiB 배열 대조/관리 힙 증감/수집 횟수를 함께 기록한다. 힙 증감에는 에디터 주변 할당도 섞일 수 있어 전체 게임 메모리/FPS 감소율로 표현하지 않는다.
- 기존 큰 성좌 그림의 한 장 소유/반환과 Point/무밉맵/CPU 읽기 불가를 유지한다. 원본 그림과 사용자 저장을 삭제하지 않는다.

## 후속 v5.3 — 돌아가기와 주요 조작의 구별

준비 화면의 뒤로 버튼을 상단 본문 시작 위치에 고정했다. 화면 기준 너비20%/높이6.7%의 클릭 영역, 흰 글자/밝은 청색 테두리/왼쪽 화살표를 쓴다. 내부 목록 복귀 버튼을 같은 고정 위치로 통합했으며 Escape도 동일한 부모 이동을 수행한다. 도감/복원/보관함/쉘터 계층을 지키고 사건이나 활동을 취소하지 않는다.

전투준비의 탐사·공략은 선택 시 밝은 청색과 짙은 글자/체크, 미선택 시 어두운 청색과 흰 글자로 표시한다. 진행은 밝은 금색과 짙은 글자/오른쪽 화살표다. 정상 상태 글자 대비와 색 이외의 선택 표시, 실제 raycast 클릭/고정 위치/복원 탭 이동을 검사한다. 새 PNG 없이 메시만 사용한다.

## 후속 v5.2 — 외형 및 실제 크기 변경

v5.1은 배치/동작 중심으로 기존 버튼·패널 외형을 많이 남겼다. 사용자가 변화가 부족하다고 지적해 다음 사항을 추가했다. 아래 기존2×2/3카드 설명은 v5.1 이력이다.

- 좁은 상태창(너비 약24% 축소), 작은 정면 초상과 이름/공격을 나란히, 상태 막대 두께 약33% 축소.
- 본문 시작점26%→20.5%. 버튼 높이44→38, 글자23→21.
- 쉘터4개 가로 행: 작은 시설 그림/이름·기능/이용 버튼. 우측 별도 도시 그림과 다음 행동.
- 의무실3개 가로 행: 이름·시간/회복 전후/체크박스/실행.
- 전투준비의 탐사·공략·진행을 한 줄로, 막대와 판 높이를 줄이고 장면을 확장. 후원판도 줄이고 시설 그림과 분리.
- 모서리가 잘린 다층 프레임과 돌출 버튼, 선택 표식. 외형은 PixelPlate/VisualSkin 코드로 그리며 새 래스터 자산이 없다.

변경 전 실제 화면은 TestResults/UISkinBefore, 최종 화면은 TestResults/PlayerQA에 남긴다. 화면 확인 도구로 점검한 시점에는 Unity/게임의 열린 창이 없었으며, 사용자가 구버전을 실행했다고 단정하지 않았다.

사용자의 후속 지시: 주시 장면, 성좌30%, 종료 후 쉘터, 의무실3카드/체크박스, 한 화면 가독성, 암울한 픽셀 게임 UI 연구, 진행도 용어 교체 및 하단 설명 제거, 실제 적 종류로 관측 기록 표시.

- [The Last Spell 공식 Steam](https://store.steampowered.com/app/1105670/The_Last_Spell/). 공식 스크린샷1105670-5는 좌상단 날짜/자원, 좌측 명령, 하단 행동을 분리한다. 1105670-7은 큰 삽화와 우측 정보 패널을 나누고 제목과 조건을 구분한다. 게임의 폐허/거점 준비 구조가 참고하기 적합하다.
- [Death’s Gambit: Afterlife 공식 Steam](https://store.steampowered.com/app/356650/Deaths_Gambit_Afterlife/). 356650-4는 어두운 장면에서 하단 적 이름/체력 막대와 강조색을 함께 사용한다. 상태를 배경 그림 속에 섞지 않는 대비를 참고한다. 356650-8은 홍보 일러스트여서 픽셀 UI 근거로 사용하지 않는다.
- [Blasphemous 공식 Steam](https://store.steampowered.com/app/774361/Blasphemous/). 774361-10은 좌상단 체력/소모품과 우상단 자원을 모아 배치하고, 어두운 면과 밝은 선으로 구별한다. 장식이 수치와 부딪히지 않는 구역 분리를 참고한다.

스크린샷은 공식 Steam appdetails의 path_full로 확인했고 원본 출처 파일은 docs/research/dark-ui에 있다. 이는 작품 관찰이며 모델 재학습이나 원작 UI/그림의 게임 내 복제를 뜻하지 않는다. 원작의 목록 스크롤은 사용자가 요청한 한 화면 가독성에 맞춰 페이지로 변형했다. Ender Lilies는 픽셀 아트 기준의 핵심 참고에서 제외했다.

## 반영

- 장면/상세와 행동 구역 분리, 어두운 단색 패널, 금색 제목/중요 상태, 각진 작은 테두리. 한국어는 배경과 분리한 실제 글꼴로 렌더링한다.
- 쉘터4시설은2×2. 각 시설의 전용 배경은 상단에 작게 유지한다.
- 의무실3카드, 키트/주사기 체크에 따라 같은 카드의 시간·회복 미리보기·실행 가능 여부 갱신.
- 예배방은 보급품/성유물 복원/후원 탭. 계승6개/페이지, 복원2개/페이지. 확인/건너뛰기와 결제의 분리는 유지한다.
- 인재4명/페이지, 계약 후보3명/페이지. 이름/정면 얼굴/종족·성격/체력/공격/정신력·허기/패시브를 연결한다.
- 성유물2개/페이지, 전승1장/페이지. 누적 기록/미달 이월/옛 데이터는 삭제하지 않는다.
- 획득 성좌6개/페이지, 급수 접기, 선택 후 그림과 능력/효과/소속/획득 당시 이야기 분할. 이벤트도 그림과 이야기·선택지를 분리한다.
- 큰 성좌 그림은 표시 중 한 장만 소유하며 떠나면 반환한다. 주시 배경도 연출 종료 시 참조를 끊고 반환한다. 새 장식 테두리는 텍스처 없이 작은 UI 메시로 그린다.
- 하루 종료 Report 상태는 유지하면서 화면을 쉘터로 돌린다. 다음 날 아침 전까지 시설 행동은 허용하지 않는다.
- '군단 봉쇄 돌파'와 진행 막대만 남긴다. 전투 시작/처치 기록은 실제 적 종류를 넣고 옛 망자 표기는 읽을 때 교체한다.

검증의 최종 실제 결과는 루트 TEST_REPORT.md와 DEVELOPMENT_STATUS.md를 참조한다.
