# 전투준비 / 균열 점수 / 적 성장 / 정면 아트 통합 제작 명령서

최신 승인: 2026-10-30. `GAME_DESIGN.md` v4.1의 통합 확정 변경을 구현한다. 사용자가 명명한 2026-10-29 1/2번째 변경점과 후속 네임드 **3점** 답변을 포함한다.

## UI

- 쉘터는 의무실·예배방·보급창고·인재관리실 네 시설. 시설 고유 배경/기능 유지.
- '악마와 균열'을 '전투준비'로 변경. 목표/진행 버튼을 쉘터에서 이동.
- 현재 군단/처치 점수/현재 봉인/적 배율/최근 기록/탐사·공략/진행을 한 화면에 배치.
- 진행도와 신위를 구분하고 한글/숫자 가독성을 우선한다. UI는 실제 Unity 컨트롤로 구현하며 예시 PNG 전체를 UI로 붙이지 않는다.

## 코어/저장

- Rules에30점 해금, 일반1/특수3/네임드3, 봉인당 체력0.5/공격0.2를 확정 상수로 둔다. 임시 기본 적 스탯/AI 가중치는 balance.json.
- Demon.progress는 처치마다 지급. 다수 일반을1회 승리로 잘못 계산하지 않는다. 탐사도 동일 군단이면 반영. 별도 신위와 거래 중복 방지 유지.
- CanReachDemon은 점수 해금 여부, 실제 악마/네임드 진입과 이벤트 발생은 균열 활동을 추가 확인한다.
- 모든 EnemyKind의 기본 스탯에 현재 봉인 수 배율을 마지막1회 적용. 네임드 원본을 바꾸지 않는다. 만료 후 재계산.
- 사망/봉인/새 균열에서 점수 초기화. 새 규칙 저장은 점수를 그대로 복원. 옛 저장은 자원/인물/성좌/봉인을 보존하며 정확히 환산 불가능한 옛 횟수 대신0점으로 전환.

## 아트/용량

- NPC12종의 개별 원본을 참조해 얼굴·어깨 정면으로 제작. 이름 연결과 얼굴/나이/복장 특징 유지.
- 시설4종과 도시/균열6개 배경 제작. 승인된 나폴레옹/요그 장면은 유지, 나머지 성좌 공백 정책 유지.
- 최종 원본/프롬프트/출처/해시 기록. 원본 PNG 보존 + 실제 표시 크기에 맞춘 초상화 import256px.
- 교체 whitelist와 참조 검사 후 옛 PNG/meta/미사용 코드만 제거. 저장·연구·사용자 파일·프로젝트 캐시 일괄 삭제 금지.
- 삭제한 파일 용량과 최종 원본 용량, 실행 시 초상화 메모리를 구분해 실제 수치를 기록.
