# 전투 장면 / v5.5

사용자의 요청은 텍스트 대신 실제 적과 맞서 공격하고, 맞으면 화면이 흔들리는 전투를 보는 것이다. 후속 지시에 따라 드래곤 빌리지식의 명확한 대결·돌진/타격 표현과 이벤트별 배경을 적용한다. [개발사 공식 Google Play 소개](https://play.google.com/store/apps/details?id=com.highbrow.game&hl=ko)의 대결 장면·단순한 타격감 설명을 참고했으며 원작 그림이나 UI를 게임 자산으로 복사하지 않았다. 웹 도구에서 공식 스크린샷 파일은 열리지 않아 그것을 직접 분석했다고 주장하지 않는다.

## 동작

Core CombatEngine은 관찰자가 있을 때 최초 화신체/적 상태와 실제 공격·반격·회피·회복 및 최종 결과를 CombatReplay에 기록한다. 기록은 순수 C#이며 Unity를 참조하지 않는다. 기존 계산/난수/시간/보상/사망·봉인은 한 번만 수행한다.

GameApp의 실제 플레이 조작·Tick·자동 사건 선택에서 전투 기록을 수집한다. 전투 전체 화면은 그 순간들을 순서대로 표시하고 표시 중 다음 자동 활동을 멈춘다. 저장에는 이미 완료된 계산 결과가 남는다. 앱 종료/재로드로 영상을 반복하거나 다시 싸워 보상을 더 주지 않는다.

화신체는 적 쪽으로 돌진/기울기, 적은 타격 색·밀림·쓰러짐을 보인다. 반격은 남은 적의 집단 공격이며 실제 합산 피해를 한 번 표시한다. 회피는 피해0/회피 동작, 반시체 회복은 실제 회복량/녹색 효과다. 피격 시 세계 계층만 흔들고 HUD는 고정한다. 이는 스프라이트 이동·회전·효과 애니메이션이며 캐릭터마다 여러 프레임을 다시 그린 걷기/베기 시트라고 주장하지 않는다.

속도는1/2/4배, 건너뛰기는 결과를 유지하고 다음 화면으로 이동한다. 전투 결과·게임 시간·자원은 표시 속도로 달라지지 않는다. 특수 동시 최대1/네임드·악마의 기존 조건도 유지한다.

## 배경

| scene | 배경 | 예 |
|---|---|---|
|ruins|기존 폐허 도시|일반 필드 전투/폐허 구조·영입|

|chapel|기존 예배방|무너진 성당/제단 사건|
|rift|기존 균열|봉쇄선·특수 좀비·악마|

활동 사건19개에 명시했고 옛 저장의 미지정 scene은 현재 정적 템플릿/활동 위치로 읽는다. 배경 데이터는 전투 규칙을 바꾸지 않는다.

## 자산과 최적화

전투용 PNG는9역할 아틀라스1장과 내부 배경1장뿐이다. 기존 도시/균열/성당과 실제 이름별 초상화를 재사용한다. 일반 인물 전신은 남녀 공통2모델, 희귀4종은 각각 종족 모델이다. 네임드 전신은 좀비 공통 모델이며 생전 얼굴은 HUD에 연결한다. 인물마다 새 전신이 있는 것처럼 표현하지 않는다.

개별 배우는 같은 아틀라스의 UV만 바꾼다. 원본 알파 범위를 확인해8px 여백을 포함한 고정 영역을 지정했으며, 균등3등분에서 생길 수 있는 옆 스프라이트 섞임을 막았다. 필터Point/밉맵 없음/CPU 읽기 없음/무압축이다. 공격마다 배우·숫자·효과 오브젝트를 새로 만들지 않고 위치/색/표시만 갱신한다. 종료·건너뛰기·불러오기 시 전용 이미지 참조를 끊고 반환한다.

실제 검증 결과와 남은 범위는 루트 TEST_REPORT.md/DEVELOPMENT_STATUS.md를 따른다.
