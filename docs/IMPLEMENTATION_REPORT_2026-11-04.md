## 위임받아 보완한 설정
balance.json의 november와 정적 사건 데이터가 조정 지점이다. 확정값과 구별한다.

- 위기HP30%, 적HP25%, 허기·정신30~40. 같은 위기의 무한 팝업을 막고 폭식 소환은 매번 별도 기회.
- 질투는 임계 피격 턴을 첫 턴으로 포함, 폭식 소환군은 생성 턴 다음부터 나이를 센다. 생성한 적은 생성 당일 적 단계에는 공격하지 않는다. 흡수 시점에 재소환이 우선하면 일반 공격을 하는 다음 악마 행동에서 흡수한다.
- 퇴각 실패는 대기 중인 적 행동 순서를 계속하며 화신체 추가 공격을 만들지 않는다.
- 냉철함은 예상 이득에서 추정 피해·시간·정신 비용을 비교한다. 신중/겁이 많음은 전투·낙상을 먼저 피하고, 호전적은 전투를 우선, 고집은 최초 유효 판단을 고수한다. 정확한 AI 점수는 성격 판단의 보완 정책이며 명령 수락률 확정표와 별개다.

## 최적화
- 전투 배우·체력바·데미지·타격선을 재사용한다. 명령 창을 매 프레임 만들지 않는다. 한 프레임의 연속 코어 체크포인트는 저장1회로 합치며 사용자 조작 확정·종료 시 저장을 유지한다.
- 자동 활동/로그 공개 중 전체 화면을 다시 만들지 않고 기록행과 상태 수치만 갱신한다. 성좌 상세를 열고 자동 활동 중일 때에도 같은 화면을 유지한다.

- Point/무밉맵/CPU 읽기 불가를 유지하고 성좌·초상·성유물·전투 아틀라스·신규 환경에 PC BC7을 적용했다. 기존 환경 원본의 크기/픽셀 경계는 유지했다. 같은 해상도에서 텍스처 압축만 끄고 다시 켜서 실측했다.

- 배포용은 개발 옵션을 제거했다. 검증용 개발 빌드는 별도 Builds/QA로 분리한다. 소스 PNG는 필요 신규 아트 때문에 증가하며 원본 삭제를 용량 절감으로 가장하지 않는다.
