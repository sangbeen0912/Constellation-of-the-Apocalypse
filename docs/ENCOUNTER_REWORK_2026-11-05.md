# 통합 탐사·이벤트·전투 / 2026-11-05 인수인계

## 구현한 사용자 확정

탐사 자동 진행·이벤트·전투가 같은 Main/Location stage/Day observation을 사용한다. 왼쪽의 큰 위치 그림에서 적을 만나고 그림 아래에는 하루 기록을 유지한다. 오른쪽 같은 영역에 진행 문구·이벤트 선택·전투 신위 명령을 표시한다. 긴 설명과 하루 기록만 각 영역 안에서 스크롤하며 선택 버튼은 고정한다. 사건·전투가 바뀌어도 위치 무대와 기록 오브젝트를 교체하지 않는다.

전투에는 아군 전신을 표시하지 않는다. 적 전신/적 체력/타격 숫자·궤적/피격 움직임을 위치 그림 안에 표시한다. 화신체가 HP 피해를 받으면 위치 화면이 붉어지고 흔들리며 버튼·글자·체력바는 고정된다. 화신체의 상태는 기존 왼쪽 초상화와 HUD에서 읽는다. 전투 계산/턴 순서/군단 능력/사망·보상·저장은 기존 Core 한 곳을 사용한다.

전투 명령 공격 지정·방어·퇴각은 각각 신위1이며 거절해도 소비한다. 수락률/일회성 지정/방어 종료/독립 퇴각 판정은 그대로다. 명령 대기 시 오른쪽에 대상 순환/세 명령/명령 없이 계속을 제공한다. 건너뛰기는 명령에서 멈춘다. 필수 선택·성좌 주시 확인·도보 연출에서는 해당 선택/진행/넘기기 외 버튼을 비활성화하고 키보드 포커스를 둔다.

하루는09:00~24:00/15시간이다. 저장의 hours는 경과 시간이고 실제 시각·남은 시간은 별도로 표시한다. 비용 변환은 Rules.ActionHours 한 곳에 정의했다.

시간 감소 권능은 줄어든 기본 비용에 적용한다. 사건의 정적 원본 비용과 eventCosts는 보존하고 실행용 사본에서 한 번만 변환한다. 같은 사본의 선택 가능 여부/UI/실제 차감이 일치한다. 전투가 무료여도 최대 턴 제한과 사망·보상 원자성 검사는 유지한다. 기존15시간 초과 경과 저장은 원래 경과를 로그에 남기고 당일을 마감하도록15로 전환한다. 기존 자원·능력치·영구 기록을 보존하며 구형 사건 재구성과 시간 변환의 이중 할인을 막았다.

강화는 스탯별/화신체별1~10회10,11~20회20,21~30회30… 신위이며1회 기본값+10%p다. 복리 계산이 아니고 체력 강화가 현재 체력을 회복하지 않는다. 기존 투자치는 그대로 보존하고 투자치/10을 완료 횟수로 읽어 가격을 정한다. Invest의 예산 일괄 사용도 구간 가격을 실제로 합산해 우회하지 못한다. UI에 완료 횟수·누적 상승률·다음 강화 가격을 표시한다.

## 적 아트와 최적화

원본과 입력은 [art-manifest.json](encounter-rework-2026-11-05/art-manifest.json), [실제 생성 프롬프트](encounter-rework-2026-11-05/enemy-atlas-prompt.txt)에 기록했다. 옛 battle-actors-v1/legion-enemies-v2 PNG·meta는 encounter-rework-2026-11-05/old-runtime-art에 보관하고 Resources에서 제거했다. 옛 BattleSceneUI 코드는 같은 기록 폴더에 보관했다. - 적·아군 혼합 전투 아틀라스2장→적 전용1장. 보존된 기존 측정은 두1024×1024 BC7 합계2,098,944B, 새 편집기 실측은1,049,472B. 해당 전투 텍스처 합계50% 감소이며 게임 전체 RAM/VRAM 개선율이 아니다.

## 검증과 한계

중간 실패는 TestResults/editmode-encounter-first-fail.* 및 playmode-encounter-first-fail.*에 보존했다. 옛 시간·명령비·사건 수 기대를 최신 규칙으로 갱신하고, 반복 리롤 연출 종료 후 버튼이 복원되지 않던 실제 오류를 수정했다. 저장·사망·전투·시간 경계와 재실행 보상 방지도 회귀 검사한다. 실제 사용자 슬롯은 초기화하지 않았다.
