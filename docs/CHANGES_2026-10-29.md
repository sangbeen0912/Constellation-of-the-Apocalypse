# 2026-10-29 추가 사용자 기획

이 문서는 이전 기본 기획과 충돌할 때 우선한다. 사용자 요청에 따른 실제 기능 변경이며 임시 시안 제작만을 요청했던 이전 턴과 구분한다.

후속 아트 변경: [2026-10-30 사용자 요청](CHANGES_2026-10-30.md)에 따라 나폴레옹/요그 소토스만 성좌 아트 공백 정책을 대체하고, NPC 초상화를 추가한다. 아래는 당시 확정한 기록이다.

## 확정된 이번 변경

- 성좌 도감: 획득 성좌만 표시. 목록 이동은 휠/스크롤바. 급수별 클릭 접기/펼치기.
- 목록 표기: `진명  성좌명 / 급수`. 목록에서는 능력 설명이나 확률 설명을 노출하지 않음.
- 이름을 클릭하면 상세창. 소속, 능력 이름, 효과, 획득 당시 이벤트 제목/본문. 큰 성좌 아트 영역은 **공백**이며 성좌 이미지를 제작·삽입하지 않음.
- 획득 당시 본문은 새 획득부터 영구 데이터에 스냅샷 저장. 과거 저장은 기존 도감 이야기로 호환 표시.
- 하루 목표는 `탐사`, `공략` 두 개. 식량/물자 수색과 구조는 탐사에 포함. 회복은 상태 AI 및 의무실 기능 유지.
- 공략은 탐사보다 전투 비중이 높음. 악마 직행을 폐지하고, 여러 날 공략하여 군단의 봉쇄선을 뚫어야 본체에 도달.
- 특수 좀비는 한 전투에 한 마리만 등장. UI뿐 아니라 공개 전투 진입점에서도 제한.
- 쉘터 네 시설 각각 전용 배경. 인재 관리실은 첨부한 인재 목록처럼 인물 아이콘/이름/능력치/상태를 정렬해 표시.
- 임시 NPC 아이콘 여러 개 제작, 이름과 아이콘을 안정적으로 연결. 레퍼런스의 팔레트를 복사하는 것이 아니라 픽셀 단위/명암/실루엣/가독성을 참고.

## 임시 구현값

- `balance.json`: 균열별 최소 공략3일 + 해당 공략 중 전투6회 승리. 최종 균열 난이도 확정값이 아니며 독립 설정 항목.
- 하루 여러 번 목표 버튼/저장 로드를 반복해도 같은 날짜는 공략 횟수1회. 진입로 전투 승리는 적 수가 아니라 전투 조우 단위.
- 진입로는 회차 저장에 유지. 사망 후 군단 철수/균열 재등장 시 새로운 진입로로 초기화.
- `content.json`: 성좌명과 소속은 UI 검증용 초기 설정. 올림포스/에덴/아발론 등의 분류를 포함하며 정식 세계관 확정으로 간주하지 않음.
- NPC32×32 아이콘12종, 시설480×72 배경4종. 기존 코드 기반 텍스처를 확장한 임시 리소스. 성좌 아트는 만들지 않음.
- NPC 이름의 안정적인 해시와 이름 어미로 아이콘 결정. 저장/불러오기, 재실행, 인재 목록/후보/현재 화신체에서 같은 이름은 같은 아이콘. 새 이름에도 추가 난수 소비 없음.
- 기존 저장 Goal 숫자0/1/2는 탐사(0)로 호환, 공략은 기존 숫자3 유지. 기존 저장 파일 삭제 및 저장 버전 강제 초기화 없음.

## 검증

도감 필터/접기/진명·성좌명·소속, 획득 본문 스냅샷, 레거시 목표 호환, 특수 좀비1마리, 공략 다일/돌파/저장/전투 비중, 아이콘12종/시설4종, 실제 휠 스크롤 및 상세 아트 공백을 자동 테스트에 추가했다. 실제 실행 결과는 `TEST_REPORT.md`에 기록한다.
