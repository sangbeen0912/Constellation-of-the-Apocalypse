## 적용
- 작은 의무실·보급창고·인재관리실 배경: 1672×941 → 512×288.
- 도시·균열·건물 내부·예배방·성좌 주시 배경: 약1672×940/941 → 1024×576.
- 위8개 배경의 RGB24를 PC BC7 고품질로 전환. 화면 비율/Point/무밉맵/CPU 읽기 불가 유지.
- 성좌 일러스트는 원본 크기 유지, 얼굴256px/성유물128px/전투 아틀라스1024px/6지역 아틀라스2048px 유지. 여러 장면을 담은 아틀라스는 각 칸이 지나치게 작아지지 않게 했다.
- Windows Mono의 미사용 관리 코드 제거 Medium, 실제 사용하는 기존 입력 시스템만 활성화. 게임 계산·밸런스·저장 형식 변경 없음.
- 실행에 필요 없는 배포 심볼54개/3,009,784바이트는 windows-symbols.zip(1,396,476바이트)에 보관. ZIP 항목의 길이와 SHA256을 원본과 비교한 뒤 배포 폴더에서 제거했다. tools/trim-symbols.ps1를 verify.ps1에 연결해 이후 재빌드에도 적용한다.
- 별도 QA 심볼도 동일한 과정으로 보관했고 심볼 없는 QA에서 실제 실행을 통과했다. 검증용 중복 빌드는 최종 확인 후 검증된 Builds/QA 경로에서 삭제했다.
