- 탐사/전투 공용 시계는 시각·위치·화면·표시 모드가 달라질 때 갱신한다. 같은 시각에 전투를 끝내도 탐사 표시로 돌아온다.
- 기록60행은 원문이 달라진 행만 용어 치환/표시한다.350개 제한에서 오래된 기록이 밀려나거나 중간 기록이 수정돼도 갱신한다. 화면 재생성 때 캐시를 비운다.
- 버튼 탐색은 매번 새 배열을 만들지 않고 재사용 List에 담는다. 필수 선택/진행의 잠금 조건은 기존과 같다.
- 저장 JSON의 공백/들여쓰기만 제거했다. 버전·필드·저장 빈도·임시 파일 검사·백업·원자적 교체는 유지했다. 기존 들여쓰기 JSON도 읽는다.
- 게임 규칙·밸런스·정적 콘텐츠·아트 파일/해상도는 이번에 바꾸지 않았다. Resources 원본110,870,743B/아트56개가 전후 동일하다.
- 현재 배포111,581,318→111,583,224B. 약112MB 수준을 유지하며, 이번 작업은 실행 경로와 저장 최적화다. 코드 캐시 추가 때문에 배포가1,906B 증가했으며 용량 감소로 보고하지 않는다.
