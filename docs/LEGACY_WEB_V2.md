# 0. 최우선 지시

너는 이 프로젝트의 책임 개발자, 게임 프로그래머, UI 개발자, QA 엔지니어다.

사용자는 코드를 직접 작성하지 않는다. 따라서 개발, 환경 구축, 테스트 실행, 오류 수정, 코드 리팩터링, 저장 데이터 검증을 가능한 범위에서 모두 자율적으로 수행하라.

목표는 문서나 목업이 아니라 실제로 PC 웹브라우저에서 처음부터 끝까지 플레이할 수 있는 게임을 제작하는 것이다.

반드시 지켜야 할 규칙:

1. 이 명령서의 확정된 게임 규칙을 임의로 바꾸지 않는다.
2. 미확정된 값은 임시 설정 파일에 넣고 문서에 표시한다.
3. 기능 하나를 구현할 때마다 관련 테스트를 작성하고 실행한다.
4. 오류 발생 시 원인을 분석해 직접 수정한 뒤 재검증한다.
5. 테스트 실패를 숨기거나 기능을 삭제해서 통과시키지 않는다.
6. 사용자가 코드를 직접 수정하도록 요구하지 않는다.
7. 개발이 중단되더라도 진행 상황과 미완료 작업을 프로젝트 파일에 남긴다.
8. 테스트하지 않은 기능을 검증 완료라고 보고하지 않는다.

# 2. 세계관과 승리 조건

플레이어는 성좌이며, 인간 화신체를 후원한다.

화신체는 NPC로서 자동으로 식사, 이동, 탐색, 전투, 휴식 등의 행동을 수행한다.

플레이어는 중요한 이벤트에 개입하고 신위를 사용해 화신체를 성장시킨다.

세계에는 7대 죄악에 해당하는 악마가 존재한다.

악마 종류:
- 교만
- 탐욕
- 색욕
- 질투
- 폭식
- 분노
- 나태

악마들은 무저갱의 균열을 통해 지상에 좀비 군단을 보낸다.

좀비의 기원은 바이러스가 아니라 악마가 지옥에서 불러낸 망자다.

승리 조건:
7명의 악마를 동시에 봉인한 상태가 되면 즉시 승리한다.

지상의 활성 균열은 언제나 최대 1개다.

악마의 개별 전투 기믹은 아직 미확정이므로 기본 전투 시스템을 먼저 만들고 설정 데이터로 추후 추가할 수 있게 한다.

# 3. 하루 진행 시스템

하루는 24시간을 기준으로 계산한다.

흐름:
1. 아침 상태 확인
2. 쉘터 및 예배당 활동
3. 하루 목표 설정
4. 하루 진행 버튼 클릭
5. NPC 자동 행동
6. 일반 이벤트 자동 처리
7. 중요 이벤트 발생 시 플레이어 선택
8. 선택 결과 반영
9. 남은 행동 진행
10. 하루 정산
11. 다음 날 시작

일반 하루 중요 이벤트 목표: 2~4개

균열 공략 하루 중요 이벤트: 최대 5개

이벤트 개수를 억지로 채우지 않는다.

행동마다 실제 게임 내 시간이 소모된다.

로그 출력 속도:
- 일반: 0.8초
- 빠르게: 0.2초
- 즉시 표시

로그 출력 속도는 실제 시뮬레이션 결과에 영향을 주어서는 안 된다.

중요 이벤트 선택을 기다리는 동안 진행을 멈추고, 선택 후 이어서 처리한다.

# 4. 화신체

게임 시작 시 무작위 NPC 3명을 보여준다.

플레이어는 이 중 한 명을 첫 화신체로 선택한다.

기본 능력치:
- 체력
- 공격력
- 정신력
- 허기

캐릭터마다 기본 능력치와 성격이 다르다.

성격은 행동 선택에 영향을 준다.

일부 NPC는 성좌의 명령을 거부할 수 있다.

NPC의 행동 AI는 성격과 현재 상태에 따른 가중치 기반 선택으로 구현한다. 별도의 외부 AI API는 사용하지 않는다.

# 5. 허기와 정신력

최대 허기: 100
최대 정신력: 100

수치는 0~100으로 제한한다.

허기는 높을수록 배부른 상태다.

식량 1개 사용 시 허기 +1.

허기는 실제 활동에 따라 감소한다.

아무 활동 없이 날짜만 바뀌었다고 별도의 허기 감소를 중복 적용하지 않는다.

허기가 50 미만이면 자동 식사가 발동한다.

자동 식사는 보유 식량을 사용하여 가능한 만큼 먹는다.

허기 100에 도달하면 중단한다.

식량이 부족하면 사용 가능한 식량까지만 소비한다.

## 활동별 허기 감소

다음은 초기 밸런스 설정값이다.

- 수면: 시간당 -1
- 휴식·치료: 시간당 -2
- 일반 이동: 시간당 -3
- 물자 수색: 시간당 -4
- 탐색·정찰: 시간당 -5
- 일반 전투: 시간당 -7
- 균열 공략·강행군: 시간당 -8

이 수치는 아직 최종 확정된 밸런스가 아니다.

24시간 동안 쉬지 않고 다양한 활동을 수행하면 허기 100이 거의 소모되는 수준을 목표로 테스트하고 조정안을 보고한다.

전투 시간이 지나치게 짧아 허기 소모가 사실상 0이 되는 경우를 검토한다.

게임 내 모든 소수점 계산은 중간값의 정밀도를 유지하고 최종 적용값을 반올림한다.

## 공복과 착란

허기 30 미만: 공복

정신력 30 미만: 착란

공복 또는 착란 상태에서는 플레이어가 그날의 이벤트 선택에 개입할 수 없다.

매우 중요:
이벤트 자체는 중단되지 않는다.

NPC는 계속 자동으로 활동하고 전투하며 식사와 휴식도 할 수 있다.

이벤트에서 선택이 필요하다면 NPC가 성격과 상태에 따라 자동 선택한다.

그날 한 번 조종권을 잃으면 수치가 회복되어도 해당 날짜의 선택권은 복구되지 않는다.

다음 날 정상 상태라면 선택권을 다시 제공한다.

허기 0: 굶주림에 의한 자결 및 사망 처리

정신력 0: 정신적 붕괴에 의한 자결 및 사망 처리

전투 중 허기나 정신력이 0이 된 경우에는 전투 중 사망으로 판정한다.

# 6. 성좌 획득 이벤트

성좌의 힘은 이벤트로만 획득한다.

예배당에서 성좌를 구매하는 기능은 없다.

하루에 성좌 획득 이벤트는 최대 1회만 발생한다.

성좌 획득 이벤트의 일일 발생 확률은 40%로 확정한다.

이는 매일 독립적으로 판정하는 확률이다. 강제 이틀 주기나 확정 등장 보장은 없다.

성좌 획득 이벤트가 발생한 후 등급을 추첨한다.

등급 확률:
- 위인급 50%
- 설화급 35%
- 신화급 10%
- 외신급 5%

동일한 성좌를 두 번 획득할 수 없다.

획득 완료된 성좌는 추첨 대상에서 제외한다.

특정 등급의 성좌를 전부 획득하면 해당 등급을 제외하고 나머지 등급의 원래 가중치를 비례 재분배한다.

모든 성좌를 획득하면 성좌 획득 이벤트 자체를 생성하지 않는다.

성좌 이벤트 처리:
1. 이벤트 발생 여부 확인
2. 획득 가능한 등급 확인
3. 등급 확률 재계산
4. 등급 추첨
5. 해당 등급의 미획득 성좌 선정
6. 성좌 전용 이야기 출력
7. 플레이어의 이야기 확인
8. 해당 성좌 영구 해금
9. 영구 저장

성좌 획득 이벤트에는 성공·실패 선택지가 없다.

이야기를 확인하면 반드시 획득한다.

공복과 착란으로 플레이어 조종권을 상실한 날에도 이야기 확인과 성좌 획득은 가능하다.

성좌 이야기는 실제 게임 내 시간 추가 소모 0분으로 처리하는 초기 제안값을 사용한다.

성좌 이벤트 자체의 중요 이벤트 슬롯 처리와 화면 연출은 일관된 공통 시스템으로 구현한다.

# 7. 성좌 등급과 계승

성좌 등급:
- 위인급
- 설화급
- 신화급
- 외신급

등급별 계승 비용:
- 위인급 30 신위
- 설화급 70 신위
- 신화급 150 신위
- 외신급 300 신위

성좌를 이벤트에서 획득하면 영구 해금된다.

영구 해금된 성좌의 힘은 예배당의 후원 메뉴에서 화신체에게 계승할 수 있다.

한 화신체에게 여러 성좌의 힘을 계승할 수 있다.

보유한 성좌의 수에 따라 추가 비용이 증가하지 않는다.

계승하지 않은 성좌는 현재 화신체에게 능력을 제공하지 않는다.

능력 구현 규칙:
- 위인급은 단일 효과 하나
- 설화급은 조건부 고유 효과
- 신화급은 기존 게임 시스템에 강력한 영향
- 외신급은 특별한 권능을 가지되 대규모 독립 시스템은 만들지 않음
- 성좌 능력 효과 로직은 가능한 한 재사용
- 동일 계승으로 보상이 중복 청구되지 않도록 검증

# 10. 예배당과 쉘터

2. 예배당
3. 보급 창고
4. 인재 관리실

예배당 기능은 정확히 3개다.

1. 보급품
2. 성유물 생성
3. 후원

영웅의 힘 구매 메뉴는 삭제한다.

후원 메뉴에서 신위를 사용해 스탯을 강화하거나 영구 해금한 성좌의 힘을 계승한다.

보급 창고는 식량, 장비, 의료품, 성유물 등을 관리한다.

인재 관리실에서는 NPC의 능력치와 성격을 확인하고 화신체를 선발한다.

활성 NPC 최대 10명.

10명을 초과한 인원은 행정 업무로 전환한다.

구조·탐색을 통해 새 NPC를 확보할 수 있다.

돌연변이 NPC는 구조·탐색 등의 경로로만 획득한다.

정부 NPC는 일반 NPC만 제공한다.

새 화신체를 선발할 시점에 사용 가능한 NPC가 0명이면 정부가 NPC 1명을 보충한다.

# 11. 신위 획득

확정 보상:

- 일반 좀비 처치: +5
- 특수 좀비 처치: +10
- 악마 본체 처치: +100
- 균열 차단 성공: +300

악마 처치와 균열 차단은 별개의 보상으로 처리한다.

둘 다 성공하면 총 +400 신위를 지급한다.

적 하나의 처치 보상을 중복 지급하지 않는다.

네임드 좀비의 기본 처치 보상은 미확정이다.

보유 신위는 성좌인 플레이어의 자산으로 관리하는 초기 권장 정책을 사용한다. 화신체가 사망해도 신위가 사라지지 않도록 한다.

신위 획득 이벤트도 추가한다.

초기 이벤트 제안:

- DV-001 무너진 신전: 신위 +10~20
- DV-002 마지막 기도: 신위 +15
- DV-003 잊힌 제단: 신위 +25
- DV-004 별빛의 흔적: 신위 +10
- DV-005 생존자의 감사: 신위 +20
- DV-006 신앙의 잔재: 신위 +30

신위 이벤트 보상 수치와 등장 빈도는 초기 밸런스 제안이며 설정 파일에서 수정 가능해야 한다.

이벤트를 무제한 반복해 보상을 중복 획득하는 오류를 방지한다.

# 12. 신위 스탯 강화

스탯 하나에 신위 1 투자 시 해당 스탯 +1%.

최종 스탯:

반올림(기본 스탯 × (1 + 해당 스탯 투자 신위 / 100))

스탯의 기본값이 증가하면 보너스 수치도 재계산한다.

투자 신위와 기본 스탯을 별도로 저장한다.

모든 소수점은 최종 계산 적용 시 반올림한다.

현재 체력과 최대 체력은 분리한다.

최대 체력 증가 시 현재 체력은 그대로 유지하는 초기 권장 정책을 적용한다.

# 13. 성유물

성유물 생성 비용: 신위 100.

성유물 등급 확률:
- 위인급 50%
- 설화급 35%
- 신화급 10%
- 외신급 5%

확률 합계는 100%다.

성유물은 중복 생성 가능 상태를 기본 임시 정책으로 사용한다.

성좌의 중복 획득 금지 및 등급 소진 규칙을 성유물에 자동 적용하지 않는다.

성유물은 화신체가 장착할 수 있다.

성유물 사망 후 회수는 가능해야 한다.

초기 구현에서는 사망 시 보급 창고로 자동 회수하는 권장 정책을 사용한다.

장착 슬롯 수와 성유물 개별 능력은 미확정이므로 임시 데이터로 처리한다.

# 14. 악마 봉인

악마를 쓰러뜨리고 균열을 차단하면 해당 악마를 봉인한다.

기본 봉인 기간: 50일.

봉인 성공 당일에는 50일로 표시한다.

다음 날부터 감소한다.

요그 소토스의 힘을 계승한 화신체가 봉인했다면 해당 봉인 기간을 65일로 설정하는 초기 제안값을 사용한다.

기존 봉인의 잔여일에는 영향을 주지 않는다.

봉인 성공 후 다음 날 새로운 적격 악마의 균열이 등장한다.

악마의 출현 순서는 무작위다.

활성 균열은 최대 하나다.

봉인이 해제된 악마는 다른 활성 균열이 존재할 경우 대기 상태로 전환된다.

7명의 악마가 동시에 봉인되면 즉시 승리한다.

승리 여부는 일곱 번째 봉인 직후, 다른 봉인의 일일 감소보다 먼저 확인한다.

# 15. 사망 시스템

전투와 비전투 사망을 구분한다.

전투 중 발생한 모든 사망은 전투 사망으로 처리한다.

전투 중 허기나 정신력 0으로 사망해도 전투 사망 판정이 우선한다.

일반 좀비에게 사망하면 현재 활성 균열의 악마군단으로 편입된다.

악마에게 사망하면 해당 군단으로 편입된다.

비전투 사망은 직접적인 사망 원인과 이전 행동·이벤트를 분석한다.

원인에 가장 가까운 7대 죄악 군단으로 배정한다.

동등하게 관련된 죄악이 여러 개라면 그 후보 중 무작위로 하나를 선택한다.

굶주림으로 인한 비전투 사망은 폭식 군단으로 편입한다.

정신력 0으로 인한 사망은 정신력이 감소한 원인을 기록하고 그 원인에 맞는 군단으로 편입한다.

비전투 원인 분석은 코드에서 직접 문장 의미를 추론하지 않고 이벤트 및 행동 데이터에 지정한 원인 태그를 사용한다.

사망 프로토콜:
1. 사망 원인 기록
2. 현재 행동 즉시 중단
3. 네임드 좀비 기록 생성
4. 현재 활성 균열이 있다면 해당 군단 철수
5. 균열 폐쇄
6. 사망까지 수행한 행동과 보상 정산
7. 날짜를 다음 날로 이동
8. 사용 가능한 NPC 확인
9. 후보가 0명이면 정부 NPC 1명 지급
10. 새 화신체 선발

활성 균열이 없다면 군단 철수 단계만 생략한다.

새 화신체의 첫날에는 전투 관련 이벤트가 발생하지 않는다.

둘째 날 새 적격 악마의 균열이 등장한다.

봉인 기간은 정상적으로 하루 단위로 감소한다.

하루 정산은 중복 실행하지 않는다.

# 16. 네임드 좀비

사망한 화신체는 이후 회차에서 네임드 좀비로 등장할 수 있다.

승계하는 정보:
- 이름
- 체력
- 공격력
- 소속 악마군단

정신력, 허기, 성좌 능력은 승계하지 않는다.

사망한 화신체 객체를 그대로 재사용하지 않는다.

별도의 기록을 생성한다.

네임드 좀비의 체력이 0으로 저장되지 않도록 사망 당시 최대 체력 기반의 초기 정책을 사용한다.

등장 여부 및 배치는 악마군단 소속 데이터와 연동한다.

공복·착란으로 조종 불가 상태라면 NPC 자동 선택으로 진행한다.

이벤트는 데이터 기반으로 관리한다.

# 19. 자동 오류 수정과 검증

오류가 발생하면 다음 절차를 자동 수행한다.

1. 오류 수집
2. 관련 코드 및 데이터 조사
3. 오류 재현
4. 원인 분석
5. 실제 코드 수정
6. 오류 재현 테스트 재실행
7. 연관 기능 회귀 테스트
8. 전체 테스트
9. 수정 기록

사용자에게 코드 수정이나 수동 디버깅을 요구하지 않는다.

테스트를 통과시키기 위해 오류를 숨기거나 실패한 테스트를 삭제하지 않는다.

반복해서 실패하는 경우 최소 재현 상황을 만들고 다른 원인을 분석한다.

반드시 구현할 자동 검증:

- 성좌 이벤트 일일 발생 확률 설정이 40%인지
- 하루 성좌 획득 이벤트 최대 1회인지
- 획득한 성좌가 다시 등장하지 않는지
- 획득 완료 등급이 추첨 대상에서 제외되는지
- 성좌 전체 획득 시 이벤트가 중단되는지
- 공복·착란에서도 자동 이벤트가 진행되는지
- 공복·착란에서도 성좌 이야기를 확인하면 획득되는지
- 체력·허기·정신력의 값이 정상 범위인지
- 허기 50 미만 자동 식사와 식량 부족 처리
- 허기 또는 정신력 0 사망 처리
- 전투 중 사망의 군단 배정 우선순위
- 비전투 사망의 원인 태그 처리
- 원인 후보가 여러 죄악이면 해당 후보 중 무작위 선정
- 사망 시 군단 철수 및 균열 폐쇄
- 활성 균열이 없는 상태의 사망 처리
- 사망 후 다음 날 화신체 선발
- 후보가 0명이면 정부 NPC 1명 보충
- 새 화신체 첫날 전투 없음
- 둘째 날 균열 생성
- 지상 활성 균열 최대 1개
- 봉인 기간 50일
- 요그 소토스 사용 시 새 봉인 65일
- 봉인 성공 당일 카운트 감소 없음
- 일곱 악마 동시 봉인 즉시 승리
- 신위 보상 중복 지급 방지
- 성유물 확률 50/35/10/5
- 신위 강화 계산 및 반올림
- 저장 후 동일한 결과 재현
- 이벤트 결과 중복 적용 방지

100회 및 1,000회 수준의 자동 시뮬레이션 도구를 만든다.

실패한 시뮬레이션의 난수 시드와 게임 상태를 저장한다.

성좌 이벤트 등급 확률은 특정 등급이 소진되기 전과 후를 나누어 통계 검증한다.

신위 경제, 평균 생존 일수, 봉인 성공률, 성좌 획득 속도도 기록한다.

실제 브라우저 테스트로 버튼과 저장·불러오기를 검증한다.

4단계: 일반 전투 및 사망

5단계: 쉘터와 인재 관리

6단계: 신위 경제 및 성좌 계승

8단계: 성유물

9단계: 7대 악마 및 균열 봉인

10단계: 네임드 좀비와 회차 계승

11단계: 자동 저장 및 모든 화면 연결

12단계: 자동 시뮬레이션, 오류 수정, 브라우저 검증

각 단계 완료 후 자동으로 검증하고 다음 단계로 진행한다.
