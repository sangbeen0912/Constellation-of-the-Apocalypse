# 2026-10-30 성좌 일러스트와 NPC 초상화

후속 확정: 균열30점/현재 봉인 적 강화/쉘터·전투준비 분리/정면 재제작/미사용 정리는 [통합 명령서](IMPLEMENTATION_ORDER_2026-10-30.md)와 `GAME_DESIGN.md` v4.1을 따른다. 아래는 최초 아트 승인 이력이다.

직전 사용자가 승인한 서도윤 초상화를 이번 이미지 제작 기준으로 사용한다. 데이브 더 다이버는 픽셀 표현 연구 자료이며 색상이나 인물을 복제하지 않는다.

- 나폴레옹과 요그 소토스를 우선 제작한다. 두 성좌는 얼굴 중심 초상화 대신 권위와 규모를 드러내는 가로형 장면 일러스트다.
- 두 이미지를 해당 성좌 획득 이벤트와 획득한 성좌의 도감 상세에 동일하게 표시한다. 그림 전체 비율을 유지한다.
- 이 두 성좌에 한해 이전의 성좌 아트 공백 지시를 이번 요청이 대체한다. 나머지 성좌는 기존 공백을 유지한다.
- 기존 NPC 외형12종을 서도윤과 같은 계열의 투명 초상화로 추가하고 모든 생성 이름을 연결한다. 서도윤은 승인된 원본을 사용한다.
- 기존 이름 해시 연결을 유지하므로 저장된 인물도 같은 외형 번호를 사용한다. 64개 생성 이름 조합이12개 외형을 공유하는 기존 구조다. 64명의 서로 다른 전용 그림을 만든 것으로 표현하지 않는다.
- 확정 능력·확률·전투·등급·이벤트 본문은 아트 추가로 변경하지 않는다.

아트 파일/제작 프롬프트/자료: [art/ART_ASSETS.md](art/ART_ASSETS.md), [art/generation-manifest.json](art/generation-manifest.json).
