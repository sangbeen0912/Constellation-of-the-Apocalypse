# 종말의 성좌 아트 기준

## 최신 제작: 성좌20종 고유 장면

사용자의 전원 제작·연결 및 구도 중복 수정 지시를 반영한다. 나폴레옹/요그의 승인된 v1은 유지하고 다른18명은 인물별 장면을 새로 설계한 v2로 제작한다. 아래의 두 성좌만 표시/나머지 공백 정책은 이전 이력이다. NPC의 정면 규칙은 NPC 초상에 적용하며, 성좌의 사건 장면은 행동과 시점을 자유롭게 구성한다.

공통점은 픽셀 군집·계단 윤곽·읽히는 명암 면이다. 공통 인물 크기·정면·전신·왕좌·손에 소품을 든 자세를 템플릿으로 강제하지 않는다. 세종의 집필, 잔다르크의 기마 지휘, 제갈량의 광역 전략, 화타의 진찰, 아르테미스의 활 사냥, 헤라클레스의 하늘을 지탱하는 시련 등 행위가 권위를 만든다. 미세한 실물 고증이 확정되지 않은 의복/배경/빛 효과는 게임의 재해석으로 구분한다. 정지 그림을 애니메이션 완료로 표현하지 않는다.

선택된18개만 Resources에 넣고 구도가 거절된 생성본은 게임 빌드에 포함하지 않는다. 성좌 원본은 그대로 보존하고 Point/밉맵 없음/표시 전용 CPU 복사 없음으로 import한다. 이벤트/도감 화면이 닫히면 해당 텍스처의 마지막 사용권을 반환한다. 여러 화면이 같은 텍스처를 사용할 경우 마지막 화면이 닫힐 때만 반환한다. 전체 그림의 비율과 UV를 유지하며 읽기 쉬운 UI 글자를 그림과 분리한다.

실제 파일·프롬프트·출처는 [성좌 제작 기록](art/CONSTELLATIONS_2026-10-30.md)에 기록한다. 검증 결과는 TEST_REPORT.md를 기준으로 한다.

## 최신 제작: 2026-10-30 정면/환경 교체

NPC12종은 기존 인물 특징을 참조한 정면 초상화 v3로 교체한다. 시설4종/도시/균열 배경을 새로 제작하고 승인된 성좌2종은 유지한다. 쉘터/전투준비 확정 구조와 전체 가독성을 실제 Unity UI에 반영한다. 현재 파일·프롬프트·해시·용량 정책은 [아트 기록](art/ART_ASSETS.md), 확정 규칙은 [제작 명령서](IMPLEMENTATION_ORDER_2026-10-30.md)를 따른다. 아래 v2 및32px fallback 설명은 이전 이력이다.

## 2026-10-30 승인 초상화 후속 제작

사용자가 승인한 서도윤의 투명 픽셀 초상화를 직접 스타일 기준으로 사용한다. NPC12개 외형은 개별 PNG로 추가하며 초기32×32 코드 아이콘은 fallback으로 보존한다. 큰 원본은 전체 비율을 유지해 UI 칸 안에 표시하고 Point 필터/무압축/밉맵 없음으로 import한다. 생성 도구의 출력 해상도를 실제 논리 픽셀 제작 격자라고 단정하지 않는다.

나폴레옹과 요그 소토스는 이벤트/도감용 가로 장면으로 제작한다. 상세 내용은 [아트 기록](art/ART_ASSETS.md), [후속 사용자 기획](CHANGES_2026-10-30.md) 참조. 이 두 성좌에 대한 새 요청이 아래의 이전 공백 정책보다 우선한다. 시설 배경과 다른 성좌 그림은 이번 제작 범위에 포함하지 않는다.

## 최신 연구 기준

2026-10-29에 공식 시각 자료13개와 개발자 설명을 바탕으로 [UI·픽셀아트 연구 1차](research/DAVE_UI_ART_STUDY.md)를 작성했다. 아래 초기 시안의 제안값보다 이 연구의 확인/관찰/제안 구분을 우선한다.

- 픽셀 크기를 키우는 것만으로 아트 품질이 올라간다고 판단하지 않는다. 실루엣과 명암 면, 소품의 형태가 필요하다.
- 작은 인재 아이콘과 큰 NPC 초상화의 제작 역할을 분리한다. 원작의 원본 제작 해상도는 미확인이다.
- 우리 게임의 색조는 별도 설계한다. 데이브의 바다/식당 색감을 따라 하지 않는다.
- 배경·효과와 인물의 표현을 구분한다. 원작 전체가 같은 픽셀 격자이거나 모든 발광 효과가 금지된다고 설명하지 않는다.
- 현재 코드 기반 아이콘12종과 시설4종은 기능 검증용 임시 리소스다. 이번 연구로 최종 품질을 달성했다고 보고하지 않는다.

## 적용 방향

- 눈에 보이는 일정한 픽셀 크기와 계단형 윤곽, 큰 색면을 사용한다.
- 인물은 표정과 실루엣이 읽히는 단순하고 탄탄한 비율로 그린다. 미세한 애니메이션 일러스트식 선화와 지나친 머리카락 묘사를 줄인다.
- 배경은 큰 건물/소품 형태와 전경·중경·원경 구분으로 밀도를 만든다. 작은 텍스처를 촘촘하게 채우는 방식은 피한다.
- 재질의 형태가 읽히는 명암 면을 먼저 구성한다. 팔레트는 종말의 성좌에 맞춰 별도 설계한다. 인물의 픽셀 경계와 배경/조명 효과를 구분하여 평가한다.
- Unity 텍스처는 Point 필터 및 적절한 정수 배율을 우선 검토한다. 초상/배경을 가로세로 비율을 무시해 늘리지 않는다.
- UI 정보 배치와 한국어 가독성은 유지한다. 작은 픽셀 아이콘, 절제된 프레임과 명확한 선택 상태를 사용한다.
- 세계관은 종말의 성좌의 좀비 아포칼립스/성좌 후원 구조를 유지한다. 레퍼런스 게임의 실제 인물·배경·로고·리소스를 복제하거나 삽입하지 않는다.

## 제안 해상도 및 제작 상태

초기 시안에서 언급한 초상48~64px, 배경480×270은 검증 전 제안이었다. 데이브의 제작 규격이나 확정 사양이 아니다. 다음 제작에서는 작은 아이콘과 큰 NPC 초상을 별도로 비교하고 실제 표시 공간에서 규격을 결정한다.

초기에는 시안만 제작했다. 이후 2026-10-29 사용자 UI 변경 요청에 따라 아래 임시 리소스를 실제 프로젝트에 연결한다.

## 초기 관찰과 임시 리소스

사용자가 제공한 큰 초상/작은 NPC 목록/게임 장면을 구분한다. 작은 인물은 실루엣과 제한된 명암으로 식별하고, 초상은 눈·머리·얼굴의 형태를 픽셀 군집으로 구성한다. UI 글자는 픽셀 그림과 별개로 읽기 쉬운 크기를 유지한다. 원본의 색감은 제작 기준이 아니다.

- NPC 아이콘12종은32×32 정수 격자로 구성하고 Point 필터/무압축/밉맵 없음으로 저장한다. 화면에서는 가능한 정수 배율로 배치한다.
- 의료/예배/보급/인재 사무실 배경4종은 기존 코드 기반 PixelArt 텍스처 시스템에서 제작한다. 각 시설의 침대·제단·상자/선반·인사 게시판/단말 같은 기능적 실루엣을 구분한다.
- 현재 시설 배너는480×72이며, 이전 좌표를 세로 축소해 그리는 임시 구현의 형태 한계가 연구에서 확인됐다. 다음 아트는 목표 화면 비율로 처음부터 구성해야 한다.
- 경로: `Assets/Resources/Art/npc-00.png`~`npc-11.png`, `facility-0.png`~`facility-3.png`.
- 네이티브 소스: `Assets/Scripts/UI/PixelArt.cs`. 생성 및 Point import 설정은 `ProjectBuilder.Generate`가 관리한다.
- 성좌 아트는 사용자 지시로 추가하지 않으며, 상세창과 획득 이벤트에 큰 빈 영역을 둔다.

공식 소개는 픽셀과3D를 결합한 게임임을 명시한다. 따라서 모든 화면을 흉내 내는 단일 필터보다, 사용자 첨부에서 실제로 보이는 픽셀 크기/군집/가독성을 각각 관찰하는 것을 기준으로 삼는다. 참고: [공식 Press Kit](https://pressmintrocket.oopy.io/dave_the_diver).
