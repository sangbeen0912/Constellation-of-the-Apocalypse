# UI 작업 공간 개편 · 2026-11-11

2026-11-12 자료 정리: 이 문서는 이전 개편의 설명을 보존한 기록이다. 과거 백업·캡처·검증 원본은 사용자 요청으로 삭제했다. 현재 구현·실행 증빙은 [최신 검증 결과](../TEST_REPORT.md)를 따른다.

상태: 적용·전체 검증·Windows 배포 빌드 완료.

## 적용 근거와 실제 변화

사용자가 [연구](research/UI_UX_RESEARCH_2026-11-11.md) 이후 제작·적용을 지시했다. Shardpunk의 작업 묶기, ZERO Sievert의 절제된 HUD, Darkest Dungeon의 행동 중요도, The Last Spell의 인물 정보 묶음을 우리 게임의 확정 규칙에 맞춰 적용했다. 타 게임 그림/프레임 파일은 추가하지 않았다.

- 쉘터의 네 시설은 고정 탭이며 선택 작업이 즉시 표시된다. 초기 의무실에서 체력/정신/수면을 나란히 비교하고 체크/실행한다. 오른쪽에 탐사·공략·출발이 고정된다.
- 탐사 클릭 뒤 목적지를 같은 영역에 펼치는 A안이다. 목적지 선택만으로 시간이 흐르지 않는다. 공략의 기존 가능 조건도 유지한다.
- 후원은 횟수·현재/변경 수치·실제 합계 비용을 함께 표시한다. ×10이 가격 경계를 지나면 각각의 비용을 더한다. 부족하면 일부만 강화하지 않는다.
- 보급 5회는 기존 5회와 같은 난수·비용·아이템·자동 식사다. 결과를 같은 창에서 읽는다.
- 복원은 이번 결과와 비용을 즉시 보여준다. 전승 기록은 별도 열람하며 최종 실행에서만 지불한다.
- 획득 성좌 목록/급수 접기와 상세 그림·능력·효과·소속·획득 이야기를 병치했다. 목록과 긴 글만 내부 스크롤하며 성좌 그림은 동시에 1개만 메모리에 둔다.
- 인재를 초상·이름·주요 수치·성격/종족·희귀 패시브가 정렬된 행으로 표시한다.
- 전투 명령 대기 중 적/체력판을 직접 선택한다. 선택은 자원·시간·난수·체력을 변경하지 않는다. 공격·방어·퇴각 명령의 신위1과 거절 규칙은 기존대로다.
- 공통 장식 테두리를 줄이고 면/간격으로 묶었다. 주요 출발은 금색, 활동 선택은 청색/체크, 일반 메뉴는 어두운 철색이다. 하단 복귀는 고정한다.
- 봉인/적 배율/봉쇄 돌파는 왼쪽에 유지하며 봉인별 남은 날은 기호에 마우스를 올려 확인한다. 진행 중 표시도 갱신한다.

## 조작 수

실행 전 메뉴를 찾는 이동까지 포함한 코드/포인터 경로 비교다. 사용자의 속도·만족도를 실험한 결과는 아니다.

## 검증과 한계

최종 tools/verify.ps1 -BuildQA 종료0. Unity6000.3.23f1, EditMode374/374 + PlayMode25/25 = **399 PASS**, 실패/무시0. XML (과거 자료 삭제됨), 실행 보고서 (과거 자료 삭제됨).

기준384개에서 강화 경계/잔액 부족/보급 난수 동일성, 치료·출발 실제 포인터 경로, 명령 대상 선택의 무지출, 실제 글자 메시/수치 갱신, 빈 글자 메시의 갱신 잠금, 프리팹 스크립트 직렬화 검사를 추가했다. 기존 검사 삭제·비활성화 없음. 페이지 왕복 대신 목록 스크롤을 쓰는 부분은 모든 항목의 영역/전체 노출 가능성까지 검사한다.

최종 smoke.ps1 종료0. 이번 실행은 TestResults/PlayerQA/Runs/20261111-220005-bbb1b1d5e8c141b7831874e4f135cf20이며 새44PNG/현재 PASS/완료 로그 표식을 확인했다. 실제 포인터로 ×10 강화·5회 보급·목적지 지정·복원 확정·적 체력판 선택을 검사했다. 지하철/도보/성좌20/성유물10/전투 명령/건너뛰기/저장 재접속/폭식 소환도 회귀 통과했다.

실제 Windows 창을 Windows.Graphics.Capture로 별도 대조했다. 쉘터·후원·도감·인재·복원·전투 캡처를 확인했다. 플레이어 PNG는1920×1009이며1280×720 인수만으로 해당 크기를 검사했다고 주장하지 않는다.

자연 캠페인 시드25/22일/395단계/7동시봉인 승리와 재로드 PASS. 동일 정책1,000회는41승/4,351사망/612봉인/494,029단계로 이전과 동일하다. UI 실험의 고정 자원/스탯과 자연 캠페인은 구분하며 실제 사용자 슬롯을 초기화하지 않았다.

상태창/자원/시각은 공용 TextCore 글꼴 자산으로 표시하며 내용·색·실제 메시와 높이를 함께 검사했다. 시스템 한글 글꼴을 사용하고 글꼴 파일/샘플 이미지 아틀라스를 배포에 추가하지 않았다. 필요한 공식 TMP 셰이더2파일과 설정·스타일·줄바꿈 자료만 포함했다.

수정/보존한 실패: 복원 기록 중복 이름/높이 잘림, 새 동선과 옛 페이지 기대의 불일치, 실제 UI 생성 중 자동 시뮬레이션이 진행하던 검사 타이밍, 생성 프리팹의 글자 스크립트 참조, 증분 빌드의 level0 손상을 재현했다. 프리팹은 기본 Text로 직렬화하고 빌드는 CleanBuildCache로 다시 생성해 최종 실행을 통과했다. 당시 실패 로그를 보존했다가2026-11-12 사용자 요청으로 정리했다. 효과가 확인되지 않은 임시 GPU 복사 셰이더/읽기 동기화 코드는 제거했다.

한계: 빠른 연속 전환 직후 플레이어 캡처 일부에서 글자가 늦게 반영된 사례가 남아 있다. 안정된 실제 Windows 창에서는 정상 표시를 확인했으나 모든 중간 프레임의 무깜빡임을 검증했다는 뜻은 아니다. 추가 해상도/종횡비·다른 GPU·장시간 수동 사용성 검사는 별도다.

전체 FPS나 프로세스 RAM 개선율은 측정하지 않았다. 기존 런타임 캐시·압축/자산 해제·Point/BC7/무밉맵·배포 심볼 분리는 유지하며 새 래스터 자산은 추가하지 않는다. 변경 전 UI 코드 사본은2026-11-12 사용자 요청으로 정리했다.

배포 파일 합계111,957,908B(약111.96MB), 이전111,583,224B 대비 약0.34% 증가했다. UI 글자 렌더링 지원을 포함한 결과이며 용량이 줄었다고 주장하지 않는다. PNG56개/아트 원본110,574,441B는 그대로다. 전체 Resources 원본은110,880,278B로 설정 자료9,535B가 늘었다.
